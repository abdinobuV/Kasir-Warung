PERAN
Kamu adalah asisten pemrograman Visual Basic .NET yang membantu mahasiswa
membuat tugas kuliah. Kodenya harus mudah dipahami pemula, rapi, dan diberi
komentar berbahasa Indonesia.

TUJUAN
Buat aplikasi desktop "Kasir Minimarket" berbasis Windows Forms (VB.NET) yang
memakai konsep recordset untuk mengelola data. Ini tugas kelompok mata kuliah
Pemrograman Visual, jadi program harus lengkap, bisa dijalankan, dan mudah
dijelaskan saat presentasi.

LAMPIRAN DESAIN
Saya melampirkan gambar mockup FormKasir. Ikuti tata letak, warna, dan teksnya
semirip mungkin. Jika kamu tidak bisa melihat gambar, pakai spesifikasi tertulis
di bagian DESAIN ANTARMUKA. Jangan menambah elemen yang tidak ada di desain.

TEKNOLOGI
- Visual Basic, Windows Forms App, target framework net10.0-windows
  (BUKAN .NET Framework), SDK-style project. Buat dengan:
  dotnet new winforms -lang VB -f net10.0 -n KasirMinimarket
- Database MySQL/MariaDB dari Laragon: host localhost, port 3306, user root,
  password kosong, nama database kasir_toko. Saya mengelola database lewat DBeaver.
- Akses data dengan paket NuGet MySqlConnector (BUKAN MySql.Data dan BUKAN
  System.Data.OleDb). Jelaskan cara memasangnya.
- Recordset diwakili oleh DataTable + MySqlDataAdapter + BindingSource
  (navigasi: MoveFirst, MovePrevious, MoveNext, MoveLast, Count)
- Aktifkan Option Strict On dan Option Infer On
- Atur HighDpiMode lewat event ApplyApplicationDefaults agar tampilan tidak buram
- Hindari API yang sudah usang atau tidak tersedia di .NET modern
- Seluruh format uang dan tanggal memakai CultureInfo("id-ID")

STRUKTUR DATABASE
Berikan skrip SQL lengkap untuk dijalankan di DBeaver. Karena ini database
latihan, skrip boleh diawali DROP DATABASE IF EXISTS kasir_toko. Skemanya:

Tabel barang           : kode_barang (PK, VARCHAR 10), nama_barang (VARCHAR 100),
                         harga (DECIMAL 12,2, CHECK >= 0), stok (INT, CHECK >= 0)
Tabel transaksi        : no_transaksi (PK, VARCHAR 20), tanggal (DATETIME),
                         total, bayar, kembali (DECIMAL 12,2)
Tabel detail_transaksi : id (AUTO_INCREMENT PK), no_transaksi (FK ke transaksi,
                         ON DELETE CASCADE), kode_barang (FK ke barang,
                         ON DELETE RESTRICT), jumlah (INT, CHECK > 0),
                         harga_satuan (DECIMAL 12,2), subtotal (DECIMAL 12,2)
Semua tabel ENGINE=InnoDB. Format kode barang: B001, B002, dst.
Data contoh (8 barang), harga tiga barang pertama harus sama dengan mockup:
B001 Aqua 600ml Rp3.000, B002 Indomie Goreng Rp3.000, B003 Snack Taro Rp2.000,
lalu 5 barang minimarket lain (stok 20 sampai 120).

- Buat control kustom di file class terpisah: PanelBulat (CornerRadius, warna)
  dan TombolBulat (sudut membulat + hover). Letakkan di file sendiri agar build

PERILAKU FORMKASIR
1. Kode barang: tekan Enter di txtKodeBarang atau klik btnCari.
   - Enter: cari di database. Jika ditemukan, isi Nama dan Harga, Jumlah default 1,
     fokus ke txtJumlah. Jika tidak, tampilkan pesan "Barang tidak ditemukan".
   - btnCari: buka dialog FormCariBarang (daftar barang dari recordset, kotak cari,
     label jumlah record, tombol navigasi record). Klik ganda baris untuk memilih.
2. Subtotal dihitung otomatis dari Harga x Jumlah saat Jumlah berubah.
3. btnTambah (juga Enter di txtJumlah): tambahkan ke dgvBelanja. Jika kode sudah ada
   di keranjang, jumlahkan ke baris yang sama. Validasi: barang sudah dipilih,
   jumlah > 0, total jumlah di keranjang untuk barang itu tidak melebihi stok.
   Setelah itu Total diperbarui dan input dikosongkan.
4. btnEdit: pilih baris di dgvBelanja, datanya muncul di kolom input, ubah Jumlah,
   klik Edit untuk memperbarui baris (validasi stok yang sama).
5. btnHapus: hapus baris terpilih setelah konfirmasi, nomor urut dihitung ulang.
6. btnBersih: kosongkan semua kolom input, lalu tanya "Kosongkan juga daftar
   belanja?" (Ya/Tidak).
7. Total, Kembalian: Kembalian = Bayar - Total, diperbarui saat Bayar diketik
   (tampil Rp0 jika Bayar kurang dari Total).
8. btnProses:
   - Validasi: keranjang tidak kosong, Bayar >= Total.
   - Buat no_transaksi otomatis dengan format TRX-yyyyMMdd-001 (urut per hari,
     dihitung di dalam transaction database yang sama).
   - Dalam SATU MySqlTransaction: INSERT ke transaksi, INSERT tiap item ke
     detail_transaksi, lalu kurangi stok dengan:
       UPDATE barang SET stok = stok - @jumlah
       WHERE kode_barang = @kode AND stok >= @jumlah
     Cek RowsAffected. Jika 0, Rollback seluruhnya dan beri tahu barang mana
     yang stoknya tidak cukup. Jika sukses, Commit.
   - Setelah sukses: simpan snapshot transaksi terakhir (item, total, bayar,
     kembali, nomor, tanggal) untuk struk, aktifkan btnCetak, kosongkan keranjang
     dan input, tampilkan pesan sukses.
9. btnCetak: nonaktif sampai ada transaksi sukses. Pakai PrintDocument dan
   PrintPreviewDialog. Isi struk (font Consolas/Courier New): nama toko
   "Minimarket Sejahtera", nomor dan tanggal transaksi, daftar item
   (nama, jumlah x harga, subtotal), total, bayar, kembali, dan
   "Terima Kasih atas Kunjungan Anda".
10. btnKeluar: konfirmasi lalu tutup aplikasi.
11. Detail UX kasir: txtKodeBarang otomatis fokus saat form dibuka dan setelah
    tiap barang ditambahkan.

FORM PENDUKUNG (bagian recordset yang paling dinilai)
- FormCariBarang (dialog): DataGridView dari recordset, pencarian, label jumlah
  record, tombol navigasi Pertama/Sebelumnya/Berikutnya/Terakhir. Mengembalikan
  kode barang terpilih ke FormKasir.
- FormDataBarang (F2): CRUD master barang. DataGridView + TextBox yang tersinkron
  dengan BindingSource, tombol Tambah/Ubah/Hapus, pencarian, navigasi record,
  jumlah record. Validasi: kode tidak boleh kembar, harga dan stok angka >= 0.
  Tangkap error foreign key saat menghapus barang yang sudah pernah terjual dan
  tampilkan pesan ramah. Gaya visual mengikuti tema biru FormKasir.
- FormRiwayat (F3): daftar transaksi dengan filter rentang tanggal, total
  pendapatan, dan detail item transaksi yang terpilih di grid kedua
  (master-detail). Tema biru yang sama.

ATURAN KODE
- Semua query memakai parameter bernama (@kode, @jumlah, dst.), tidak boleh
  menggabung string input ke SQL.
- Gunakan blok Using untuk Connection, Command, dan DataAdapter.
- Bungkus operasi database dengan Try...Catch dan tampilkan pesan error ramah
  lewat MessageBox.
- Module Koneksi: connection string bersama + fungsi tes koneksi. Module Helper:
  FormatRupiah(Decimal) dan ParseRupiah(String) yang dipakai di seluruh form.
- Nama kontrol berawalan standar (txt, btn, lbl, dgv, pnl).
- Pisahkan logika berulang ke prosedur/fungsi kecil.
- Komentar berbahasa Indonesia, singkat, menjelaskan "kenapa", bukan hanya "apa".

DOKUMEN PENDUKUNG (Tahap 7)
- Minimal 10 skenario uji dalam tabel (skenario, input, hasil diharapkan, hasil
  sebenarnya): kode barang tidak ada, jumlah melebihi stok, jumlah 0 atau huruf,
  bayar kurang dari total, keranjang kosong saat bayar, barang yang sama
  ditambah dua kali, kode barang kembar di FormDataBarang, hapus barang yang
  sudah terjual, dan transaksi normal yang stoknya harus berkurang.
- Penjelasan singkat bagian recordset (DataTable, BindingSource, navigasi
  record, Count) dalam bahasa yang mudah saya jelaskan ke dosen.
- Deskripsi ERD dalam bentuk teks dan alur proses pembayaran.
- Langkah ekspor database lewat DBeaver (Tools > Dump Database) untuk
  disertakan saat pengumpulan.

PENANGANAN ERROR UMUM (jelaskan di Tahap 1)
- "Unable to connect to any of the specified MySQL hosts" (Laragon belum
  Start All atau port salah)
- "Access denied for user" (user/password salah)
- "Unknown database 'kasir_toko'" (skrip belum dijalankan di DBeaver)
- "Public Key Retrieval is not allowed" di DBeaver (set driver property
  allowPublicKeyRetrieval = true)
